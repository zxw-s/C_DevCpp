# 项目说明：

C语言程序，用来熟悉Dev-C++。程序功能包含：变量、数组、函数、指针、结构体

> Dev‑C++：Windows下免费轻量的C/C++ IDE，内置 **TDM‑GCC(GCC)** 编译器，操作简单，很多学校C语言教学在用；**只适合入门写控制台习题，不适合大型项目**。
> ⚠️重要：文件路径、文件名**禁止中文、空格**，否则编译异常、打不开文件。
> 
> Dev‑C++ 使用 MinGW 编译器，不需要配置 json，
> 
> **编辑‑编译‑运行‑调试**是图形按钮操作。

# 一、版本与安装

**1.下载：**

选择带 TDM-GCC的 **Embarcadero Dev‑C++ 6.x**（新版，编译器新，支持C11/C++17）；不要用老旧Orwell 5.11（GCC4.9.2，标准支持差）;不要下载精简版，避免缺少编译器、调试器

**2. 安装步骤：**

- 双击exe，初始语言选English，同意协议

- 安装类型选Full完整安装，不要选典型/自定义，否则缺少调试工具

- 安装路径建议改到D盘（如 D:\Dev-Cpp ），不要装C盘，**路径不要中文**。

- 安装完成后打开，首次弹窗编译器检测点 Yes 自动修复。

- 首次启动：选择编译器 `TDM‑GCC 64‑bit Release`。

**3. 切换简体中文（可选）**

顶部菜单： 工具(T) → 环境选项 → General → Language ，选择简体中文/Chinese，重启软件生效。

# 三、常用设置优化

`工具 → 编辑选项 / 编译选项`

## 1. 编辑器外观

- 字体：Consolas，字号 14；勾选显示行号。
- 开启代码补全：编辑选项 → 代码补全，勾选启用。

## 2. 语言标准设置

工具 → 编译选项 → 编译器→代码生成/优化→语言标准（std）下拉框：

- ISO C99：严格C99标准
- GNU C99：C00+GCC扩展（日常开发最常用，兼容性最好）
- C 标准：`‑std=c11`（新版编译器支持）
- C++ 标准：`‑std=c++17`

## 3. 中文乱码（Windows 高频坑）

根本原因是**源码编码、编译器输出编码、终端编码**三者不统一。

Dev‑C++ 默认源文件 GBK 编码。

- **方案 1**：用记事本转码。记事本打开文件→另存为→编码选项选择UTF-8，代码中文可以正常输出。
- **方案2**：想要 UTF‑8：编译选项加入参数：`-fexec-charset=GBK`。
- **方案3**：代码里自动切换编码：在C程序开头加入包含头文件代码`#include <stdlib.h>`,并在主函数main开头加入代码`system("chcp 65001 > nul");`切换代码页为UTF-8，并确保源文件为UTF-8无BOM格式。`> nul`用于屏蔽“活动代码页：65001”的提示行，保持输出干净。不加>nul会导致控制台多出一行干扰信息。【若保存为UTF-8 with BOM，程序可能跳过首字符或报错】

6.0+版本支持手动修改编码。路径为：`菜单：工具→编辑器选项→基本→New Document Encoding`，编码可改为UTF-8

> 不要混用 UTF‑8 文件 + GBK 执行编码，极易乱码。

## 4. 多文件项目使用

1. 文件 → 新建 → 项目 → Console Application。
2. 项目 → 添加到项目，把`.c` `.h`加入项目。

> 只有加入项目树的文件才参与编译，这点类似 VS，**不需要 CMakeLists**。

# 四、两种新建方式与项目结构

## 两种模式：

### 方式1：新建单文件源代码`.c` / `.cpp`

最常用，新手优先，单源码文件，不用项目，适合刷题、简单程序

1. 快捷键  Ctrl+N ，或菜单： 文件 → 新建 → 源代码 

2. 空白编辑页出现，必须切换英文输入法写代码（标点、括号全英文）

3. 保存文件： Ctrl+S 

- C语言：后缀名填  .c （例： test.c ）

- C++：后缀名填  .cpp （例： test.cpp ）

- 保存路径不要有中文、空格，避免编译报错

### 方式2：新建Project项目（多文件程序用）

`.dev` 项目文件，管理多个`.c/.h`文件。

1.  文件 → 新建 → 项目 

2. 选择  Console Application（控制台应用） ，选C项目/C++项目，填写项目名，选择保存文件夹

3. 自动生成main主文件，双击打开即可编写代码

## 项目目录：

```plaintext
demo/
├── demo.dev          # Dev‑C++项目文件，保存项目配置
├── main.c            # 源代码
├── calc.h
├── calc.c
└── demo.exe          # 编译生成可执行程序
```

> 没有复杂隐藏配置文件夹；`.dev` 需要保存；exe 编译产物。

# 六、新建、编译、运行第一个程序

**操作流程**：写代码 → `Ctrl+S`保存 → `F11`编译运行。

## 1.文件 → 新建 → 源代码（`Ctrl+N`）

C语言版本

```c
#include <stdio.h>

int main()
{
    printf("你好，Dev-C++！");

    // 防止防止控制台闪退运行窗口一闪而过，新手必加，需要 #include <stdlib.h>

    return 0;
}
```

C++版本

```cpp
#include <iostream>

using namespace std;

int main()
{
    cout << "你好，Dev-C++！" << endl;
    system("pause");
    return 0;
}
```

注意：所有符号 (){};"" 必须是英文，中文输入法输入标点会直接编译报错。

> `system("pause");` 新手必加，解决运行黑框一闪而过。

## 2.编译、运行程序（核心操作）

| 操作            | 菜单路径      | 快捷键 |

| 单独编译          | 运行 → 编译   | F9  |
| 单独运行          | 运行 → 运行   | F10 |
| 一键编译+运行（新手首选） | 运行 → 编译运行 | F11 |

# 七、调试（排查bug，Dev‑C++ 调试坑很多）

> ✅Dev‑C++ 默认关闭调试信息，调试**必须先开启生成调试信息**：
> 
> 工具 → 编译选项 → 编译器 →代码生成/优化 →连接器→**产生调试信息**，选择`yes`
> 
> 如果变量窗口显示`???`，全部重新编译 `Ctrl+F9`；
> 
> 单个文件无法断点调试，必须创建项目。

1. 单击行号左侧空白处，出现红色圆点 = 断点（程序运行到这里会暂停）；或者光标在行按`F5`。
2. `F5`启动调试模式/运行到下一个断点。
3. `F7`：单步执行，不进入函数内部；`Shift+F7`：跳过函数；`F8`单步进入，进入函数内部。
4. 左下角**监视窗口**：右键 → 添加监视，输入变量名，例如：`st`、`*&st`、`nums[2]`，实时看变量。监视窗口可以观察变量数值，找到逻辑错误。
5. 调试结束按 Shift+F5 停止调试

> 缺点：调试界面简陋，复杂数组、指针查看体验差，大型项目不推荐用 Dev‑C++ 调试。

# 八、新手常见问题&解决

**1. 运行窗口一闪而过**

代码末尾加上  system("pause");  即可，头文件需要加  #include <stdlib.h> 

**2. 报错：找不到编译器**

安装时选了精简版，卸载重装，选择Full完整安装；或工具→编译器选项，手动选择MinGW路径

**3. 中文乱码**

菜单：工具→编辑器选项→基本→New Document Encoding，编码改为GBK，或文件保存时选择ANSI编码

**4. 代码语法没错但编译报错**

检查输入法：所有括号、分号、引号必须是英文；文件名、保存路径不要有中文

# 九、高频坑自查清单

1. ✅**写完代码必须 Ctrl+S 保存再编译**，Dev‑C++ 不会自动保存！忘记保存会编译旧代码。
2. ✅控制台闪退：main 末尾加 `system("pause");`，头文件 `#include <stdlib.h>`。
3. ✅调试变量显示`???`：没有开启 “生成调试信息”，需要 Rebuild All 全部重编译CSDN博...。
4. ✅中文乱码：源文件编码与编译器输出编码匹配。
5. ✅新增`.c`文件，多文件模式下必须添加到项目中，否则报`undefined reference`。
6. ✅软件容易崩溃，勤按`Ctrl+S`保存代码。

# 十、Dev‑C++ 优缺点总结

✅优点：

- 体积很小，几十 MB，低配老电脑流畅；一键内置 GCC，零配置上手刷题。
- 学校教学、C 语言课后习题非常合适。

❌缺点：

- 调试功能简陋；编辑器补全弱；不适合大型项目。
- 编码问题多；现代 C++ 新特性支持有限；没有 Git 集成。

> 学习后期建议迁移到 VS / CLion / VSCode。

# 十二、Dev‑C++ 常见报错对照表

> 说明：报错信息来自底部编译日志，双击报错行可以跳转到出错代码位置。重点看  error （错误，程序不能运行）； warning （警告，可以运行，但有隐患，尽量修改）。

## 语法类错误（最高频）

| 报错提示                                       | 常见原因                                                    | 解决办法                                              |
| ------------------------------------------ | ------------------------------------------------------- | ------------------------------------------------- |
| expected ';' before                        | 少写分号 ; ，或者分号写成中文；上一行结尾漏分号                               | 语句末尾必须英文分号 ; ，检查上一行代码                             |
| expected ')' before                        | 括号不匹配，少左/右括号，中文括号 （）                                    | 全部改成英文 () ，数括号成对                                  |
| expected '{' before                        | 函数后面漏大括号 { ；括号是中文                                       | 补充英文大括号 { }                                       |
| undeclared identifier                      | 未定义标识符：变量没定义；头文件没包含；拼写错变量名                              | 1.变量先定义再使用 2.检查头文件 3.核对变量大小写、拼写                   |
| 'cout' was not declared in this scope      | C++使用cout，缺少 #include <iostream> 或 using namespace std; | 开头加上：  #include <iostream>   using namespace std; |
| 'printf' was not declared in this scope    | C语言printf没有stdio头文件                                     | 加上  #include <stdio.h>                            |
| 'system' was not declared in this scope    | 用 system("pause"); 缺少头文件                                | 加上  #include <stdlib.h>                           |
| too few arguments to function              | 函数调用参数个数不够，比如scanf、printf传参少写                           | 对照函数要求补全参数                                        |
| format '%d' expects argument of type 'int' | 格式符和变量类型不匹配，%d对应int，%f对应double                          | 修改格式符，类型保持一致                                      |

## main函数相关错误

| 报错提示                          | 原因                                  | 解决                            |
| ----------------------------- | ----------------------------------- | ----------------------------- |
| 'main' must return 'int'      | main写为 void main() ，标准C++不支持        | 改成  int main() ，结尾加 return 0; |
| multiple definition of 'main' | 一个cpp文件出现2个main函数；打开了多个带main的文件一起编译 | 一个程序只能有1个main；关闭其他源代码文件       |

## 编译/环境类报错（软件本身问题）

| 报错提示                        | 现象                        | 解决办法                                         |
| --------------------------- | ------------------------- | -------------------------------------------- |
| cannot find -lgcc  / 找不到编译器 | 点击F11无反应，提示编译器不存在         | 1.重装完整版Dev‑C++（TDM‑GCC） 2.工具 → 编译器选项，确认编译器路径 |
| No such file or directory   | 头文件找不到；文件路径有中文空格          | ①头文件名字拼写正确 ②保存路径全部英文，不要中文文件夹                 |
| permission denied           | 保存到C盘系统目录，权限不足            | 保存到D盘，文件夹名英文                                 |
| Id returned 1 exit status   | **这个不是具体错误！代表前面有error错误** | 看它上面几行真正的error信息，不要盯着这一行                     |

## Warning 警告（不阻止运行，但建议改）

| 警告信息                                   | 含义                        | 处理           |
| -------------------------------------- | ------------------------- | ------------ |
| unused variable ‘a’                    | 定义了变量a，但是全程没有使用           | 删掉没用变量，或者使用它 |
| implicit declaration of function       | 调用函数之前没有头文件，老编译器允许运行，新版报错 | 补上对应头文件      |
| comparison between signed and unsigned | 有符号和无符号数字比较               | 统一变量类型       |

## 运行时错误（编译成功，运行崩溃黑框闪退）

编译0错误，但是运行直接退出、卡死、乱输出

**1. 窗口一闪而过**

- 原因：程序跑完直接结束，看不到输出

- 修复：main末尾  system("pause"); ，记得引入  #include <stdlib.h> 

**2. 程序运行直接崩溃 stopped working**

- 常见：数组越界、访问a[100]但数组只有5个元素；scanf没加 & 取地址；除以0

- C语言scanf： scanf("%d", &a); ，变量前面勿忘 &

**3. 控制台中文乱码**

- 工具 → 编辑器选项 → 字体，编码选择GBK；保存文件编码ANSI，不要UTF‑8

## 排错小技巧（新手必记）

1. 优先看**第一条error**，后面一堆错误经常是第一个错误连锁引发的，改完第一个，一堆报错直接消失。

2. 标点符号全部切换英文输入法写代码，中文标点是新手头号杀手。

3. 保存路径、文件名**不能中文、空格**。

4.  Id returned 1 exit status 只是结果，往上翻找真正错误。

### 典型踩坑示例

❌错误代码（中文分号）

```c
#include<stdio.h>
int main()
{
    printf("hi")； //这里分号中文！报错 expected ';'
    return 0;
}
```

✅正确

```c

{
    printf("hi");
    system("pause");
```

# 十三、Dev‑C++ 综合练习代码

Dev‑C++ 使用 MinGW 编译器，不需要配置 json，**编辑‑编译‑运行‑调试**是图形按钮操作。
文件名：`devcpp_demo.c`

> 功能包含：变量、数组、函数、指针、结构体，用来熟悉 Dev‑C++ 全套操作。

```c
#include <stdio.h>

typedef struct Student
{
    int id;
    char name[20];
    double score;
}Student;

//指针修改结构体分数
void setScore(Student *s, double sc)
{
    s->score = sc;
}

//求数组平均值
double avg(int arr[], int n)
{
    int sum = 0;
    for(int i = 0; i < n; i++)
    {
        sum += arr[i];
    }
    return (double)sum / n;
}

int main(void)
{
    int nums[4] = {60,72,85,93};
    Student st = {101,"Tom",78.5};

    printf("数组数据：");
    for(int i=0;i<4;i++)
    {
        printf("%d ",nums[i]);
    }
    double a = avg(nums,4);
    printf("\n数组平均值：%.2f\n",a);

    printf("\n学生：id=%d name=%s score=%.1f\n",st.id, st.name, st.score);
    setScore(&st,90.0);
    printf("指针修改后分数：%.1f\n",st.score);

    printf("\n请输入一个整数：");
    int x;
    scanf("%d",&x);
    printf("你输入的是：%d\n",x);

    system("pause");   // 暂停，防止窗口闪退
    return 0;
}
```

**解决控制台闪退**

增加 `#include <stdlib.h>` 和 `system("pause");`，运行结束黑窗口不会一闪直接关闭，方便看结果。

> 小提示：`system("pause");` 只适合Windows调试看结果，**考试、OJ提交代码不要带这一行**，会判错。

运行输出示例

```plaintext
数组数据：60 72 85 93
数组平均值：77.50

学生：id=101 name=Tom score=78.5
指针修改后分数：90.0

请输入一个整数：66
你输入的是：66
```

## Dev‑C++ 调试（重点！和VS Code不一样）

> ⚠️Dev‑C++ 默认关闭调试信息，必须设置：
> 工具 → 编译选项 → 编译器 → 勾选 **加入调试信息**。

1. 设置断点：代码行号左边**鼠标点击**，出现红色圆点。
2. 菜单：运行 → 调试（快捷键 `F5`）进入调试模式。

调试快捷键：

- `F7`：单步执行（Step into，进入函数内部）
- `Shift+F7`：单步跳过（Step over）
- `Ctrl+F7`：运行到光标处
- `F4`：停止调试
- 左下角**监视窗口**：右键 → 添加监视，输入变量名，例如：`st`、`*&st`、`nums[2]`，实时看变量。

> 练习：断点打在 `setScore(&st,90.0);`，F7跳进函数内部，观察指针修改结构体成员。

## Dev‑C++常见坑

1. 调试看不到变量值、断点红色圆点变成灰色：一定要勾选「**加入调试信息**」。

2. 一闪而过：程序结束黑窗口直接关闭。两种解决：
   
   - main最后加 `system("pause");` 需要头文件 `#include <stdlib.h>`
   
   ```c
   #include <stdlib.h>
   int main()
   {
     //你的代码
     system("pause");
     return 0;
   }
   ```

3. 保存后缀不要写成 `.cpp`，写C代码保存为 `.c`。

4. scanf输入：调试模式下，输入要在弹出的黑色窗口，不要在IDE内部。

5. 老版本Dev‑C++对C99支持差，循环内`for(int i=0;…)`报错：老版本默认C89，for循环里面写`int i`报错，设置编译器支持C99。

解决：工具 → 编译选项 → 在编译器命令加入：`‑std=c99`。

## Dev‑C++ 和 VS‑Code简单对比

- Dev‑C++：图形界面，零配置，适合刚入门；调试功能比较简陋。
- VS‑Code：需要配置tasks.json、launch.json；调试功能强大，监视、堆栈面板完善。

# 十四、Dev‑C++ 综合演示代码

文件名：`devcpp_core.c` 覆盖：变量、输入输出、数组、函数、指针、结构体，专门用来熟悉 Dev‑C++ **新建、保存、编译、运行、断点调试**全套核心操作。

> 包含 `system("pause")`，Windows运行不会闪退。

```c
#include <stdio.h>
#include <stdlib.h>

// 结构体
typedef struct Student
{
    int id;
    char name[20];
    double score;
} Student;

// 指针作为函数参数，修改外部结构体
void setScore(Student *s, double newScore)
{
    s->score = newScore;
}

// 数组求平均值
double getAvg(int arr[], int n)
{
    int sum = 0;
    for(int i = 0; i < n; i++)
    {
        sum += arr[i];
    }
    return (double)sum / n;
}

int main(void)
{
    int data[4] = {80, 92, 76, 88};
    Student stu = {1001, "张三", 82.5};

    printf("=== Dev‑C++核心功能测试 ===\n");

    // 数组输出
    printf("数组数据：");
    for(int i = 0; i < 4; i++)
    {
        printf("%d ", data[i]);
    }
    double avgVal = getAvg(data, 4);
    printf("\n数组平均值：%.2f\n", avgVal);

    // 结构体 + 指针
    printf("\n修改前学生：id=%d，姓名=%s，分数=%.1f\n", stu.id, stu.name, stu.score);
    setScore(&stu, 94.0);
    printf("指针修改后分数：%.1f\n", stu.score);

    // 键盘输入
    int num;
    printf("\n请输入一个整数：");
    scanf("%d", &num);
    printf("你输入的数字：%d\n", num);

    system("pause");
    return 0;
}
```

## Dev‑C++ 核心操作完整流程

### 1.新建保存

1. 文件 → 新建 → 源代码

2. 粘贴代码，`文件 → 保存`，文件名：`devcpp_core.c`，保存类型选 **C source files(*.c)**
   
   > ⚠️不要保存为 `.cpp`

### 2.开启调试信息（调试必须配置）

工具 → 编译选项 → 编译器 → 勾选 **加入调试信息** → 确定。

### 3.编译 & 运行

- `F9`：编译，下方窗口看报错信息（语法错误、行号）
- `F11`：编译并运行，弹出黑控制台窗口

### 4.断点调试（Dev‑C++最重要功能）

1. 在代码行号**左侧点击**，出现**红色圆点**即为断点。
   
   > 建议断点位置：
   > 
   > - `double avgVal = getAvg(data, 4);`

   调试快捷键：

- `Ctrl+F7`：运行到光标位置

- `F4`：停止调试
3. **监视窗口**（左下角）：右键 → 添加监视
   输入表达式查看变量：

